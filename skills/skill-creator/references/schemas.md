# Eval Schema Reference

Full schema for `evals/evals.json` and `eval_metadata.json` used by the skill-creator workflow.

---

## `evals.json` — Top-Level Schema

```json
{
  "skill_name": "string (required) — kebab-case name matching the skill's frontmatter",
  "version": "string (optional) — e.g. '1.0', '2.3'",
  "description": "string (optional) — what this eval set covers",
  "evals": [ /* array of EvalCase objects */ ]
}
```

---

## `EvalCase` Object

```json
{
  "id": "integer (required) — unique within this eval set",
  "prompt": "string (required) — the exact user prompt sent to the agent",
  "expected_output": "string (required) — human-readable description of success",
  "files": [
    {
      "path": "string — path relative to workspace",
      "content": "string (optional) — inline content for small files",
      "description": "string (optional) — what this file represents"
    }
  ],
  "assertions": [ /* array of Assertion objects */ ],
  "tags": ["string (optional) — e.g. 'edge-case', 'happy-path', 'regression'"],
  "qualitative": "boolean (optional, default false) — if true, assertion grading is human-reviewed"
}
```

---

## `Assertion` Object

Each assertion tests one specific, objectively verifiable condition.

### Type: `contains`
Output must include the specified substring.
```json
{
  "type": "contains",
  "name": "Report includes executive summary header",
  "target": "output",
  "value": "## Executive Summary"
}
```

### Type: `not_contains`
Output must NOT include the specified substring.
```json
{
  "type": "not_contains",
  "name": "No placeholder text left in output",
  "target": "output",
  "value": "TODO"
}
```

### Type: `matches_regex`
Output matches a regular expression.
```json
{
  "type": "matches_regex",
  "name": "Output contains a valid ISO date",
  "target": "output",
  "pattern": "\\d{4}-\\d{2}-\\d{2}"
}
```

### Type: `file_exists`
A specific file was created in the expected location.
```json
{
  "type": "file_exists",
  "name": "Output CSV file was created",
  "path": "outputs/report.csv"
}
```

### Type: `file_contains`
A specific file contains the expected content.
```json
{
  "type": "file_contains",
  "name": "CSV has header row",
  "path": "outputs/report.csv",
  "value": "name,value,timestamp"
}
```

### Type: `json_valid`
A file or output is valid JSON.
```json
{
  "type": "json_valid",
  "name": "Output is parseable JSON",
  "target": "output"
}
```

### Type: `custom`
Human-reviewed assertion — graded qualitatively.
```json
{
  "type": "custom",
  "name": "Writing style matches brand voice",
  "description": "Check that the output is warm but professional, avoids jargon",
  "qualitative": true
}
```

---

## `Assertion` Common Fields

| Field | Type | Required | Description |
|:---|:---|:---|:---|
| `type` | string | ✅ | One of the types above |
| `name` | string | ✅ | Short, clear name — displayed in the review report |
| `target` | string | — | `"output"` (default) or `"file"` |
| `qualitative` | boolean | — | If true, skip automated grading; flag for human review |
| `weight` | number | — | Relative importance (default: 1.0) for weighted scoring |

## `eval_metadata.json` — Per-Run Metadata

Written to each `<eval-name>/` directory during a run.

```json
{
  "eval_id": 1,
  "eval_name": "descriptive-kebab-case-name",
  "prompt": "The exact prompt used for this run",
  "skill_version": "string (optional)",
  "assertions": [
    /* same Assertion objects as in evals.json */
  ],
  "notes": "string (optional) — any context about this specific run"
}
```

---

## `timing.json` — Per-Run Performance Data

Written to `with_skill/` and `without_skill/` (or `old_skill/`) directories.

```json
{
  "total_tokens": 84852,
  "duration_ms": 23332,
  "total_duration_seconds": 23.3,
  "model": "string (optional) — model used",
  "timestamp": "ISO 8601 string"
}
```

  "generated_at": "ISO 8601 timestamp",

      "eval_id": 1,

---

## Naming Conventions

- `eval_name`: Use descriptive kebab-case (e.g., `basic-csv-transform`, `edge-case-empty-input`)
- `name` (assertion): Write as a complete readable statement (e.g., `"Output file has correct headers"`)
- Eval directories: Named after `eval_name`, NOT `eval-0`, `eval-1`

## Full `evals.json` Example

```json
{
  "skill_name": "csv-transformer",
  "version": "1.0",
  "description": "Tests for the CSV transformation skill across happy paths and edge cases",
  "evals": [
    {
      "id": 1,
      "prompt": "Transform the attached sales_data.csv file: normalize all dates to ISO format, remove duplicate rows, and output as clean_sales.csv",
      "expected_output": "A CSV file with ISO-formatted dates, no duplicates, same column structure",
      "files": [
        {
          "path": "inputs/sales_data.csv",
          "description": "Raw sales data with inconsistent date formats and some duplicate rows"
        }
      ],
      "assertions": [
        {
          "type": "file_exists",
          "name": "Output file clean_sales.csv was created",
          "path": "outputs/clean_sales.csv"
        },
        {
          "type": "file_contains",
          "name": "Output CSV has correct header",
          "path": "outputs/clean_sales.csv",
          "value": "date,product,amount"
        },
        {
          "type": "matches_regex",
          "name": "Dates are in ISO format",
          "target": "file",
          "path": "outputs/clean_sales.csv",
          "pattern": "\\d{4}-\\d{2}-\\d{2}"
        },
        {
          "type": "custom",
          "name": "No duplicate rows remain",
          "description": "Manually verify row count is lower than input and no identical rows exist",
          "qualitative": true
        }
      ],
      "tags": ["happy-path"]
    },
    {
      "id": 2,
      "prompt": "Transform this empty CSV file",
      "expected_output": "Graceful error message explaining the file is empty; no crash",
      "files": [
        {
          "path": "inputs/empty.csv",
          "content": "date,product,amount\n"
        }
      ],
      "assertions": [
        {
          "type": "not_contains",
          "name": "No Python traceback in output",
          "target": "output",
          "value": "Traceback (most recent call last)"
        },
        {
          "type": "contains",
          "name": "Output mentions empty file",
          "target": "output",
          "value": "empty"
        }
      ],
      "tags": ["edge-case"]
    }
  ]
}
```
